# 🎓 CertifyCraft — Dynamic Certificate Generator & Verification Suite

CertifyCraft is a client-side web application built with modern JavaScript, HTML5, and CSS3 designed to generate, customize, verify, and batch-export professional certificates for academic institutions, hackathons, and corporate workshops.

🌐 **Live Demo:** [Try CertifyCraft Online](https://YOUR_GITHUB_USERNAME.github.io/certificate-generator/)

---

## ✨ Features

* **6 Preset Themes:** Classic Gold, Modern Corporate, Tech Terminal, Luxe Dark, Academic University, and Hackathon Winner.
* **Batch CSV Generation:** Input multi-recipient datasets to compile dynamic multi-page PDF certificates in seconds.
* **Dynamic QR Verification:** Auto-generates unique certificate IDs and verification QR codes mapped on canvas.
* **Interactive Signature Pad:** Built-in digital signature drawing pad with support for PNG image uploads.
* **Full Design Customization:** Real-time font selection, color pickers, and dynamic text composition.
* **Multi-Format Export:** High-definition PNG export, single-page PDF, multi-page batch PDF, and direct browser printing.

---

## 🛠️ Tech Stack & Libraries

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **PDF Rendering:** `jsPDF`
* **Canvas Capture:** `html2canvas`
* **Digital Signatures:** `signature_pad`
* **QR Generation:** `QRCode.js`
* **Icons:** `Lucide Icons`
